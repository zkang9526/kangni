# V3.0 最终状态

## 结论

V3.0 是当前唯一保留的公开数据基线包，可以在另一台设备上直接训练和复现实验；它**不能声明为完全满足 V4.0 的最终量产验收数据集**。

## 已满足的训练基础

- FCW：BDD100K 2D 目标检测 + nuScenes Mini 的障碍物、投影框和米制距离管线。
- DMS 闭眼：MRL Eye 红外眼部 `closed/open` 分类。
- 后排占用预训练：SVIRO BMW i3 灰度单座椅 7 类分类。
- 本地 NTHU 疲劳二分类：仅作为弱标签辅助，不作为独立事件真值。

## V4.0 尚未满足的验收项

1. 项目 166° 鱼眼 IR 摄像头、双 A 柱安装位和三轮车真实环境。
2. 连续 `head_down` 低头事件及闭眼持续时长真值。
3. 后排儿童安全带扣合与物理座椅传感器同步标签。
4. 相机—雷达时间同步、目标关联、相对速度、方位角和 TTC。
5. 130 m 探测、10 m 内不少于 8 个目标、报警延迟和准确率的道路证据。

V3.0 内的合成 SVIRO 只用于占用预训练，NTHU 只用于弱辅助；二者不能作为上述项目验收证据。

## 使用前检查

```bash
python scripts/verify_datasets.py
```

返回 `PASS` 后再训练。具体训练命令见 [training.md](training.md)。
